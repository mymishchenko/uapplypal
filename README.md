# UApplyPal

A personal university admission agent: programs, requirements, deadlines, real cost, scholarships,
exams and documents in one place, with every fact linked to its source and verification status.

```bash
npm install
npm run dev:server   # API on http://127.0.0.1:3000
npm run dev:client   # UI on http://localhost:5173
npm test
```
